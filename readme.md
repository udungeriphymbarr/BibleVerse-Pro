# 📖 BibleVerse Pro

> A modern Bible Study Progressive Web App built with HTML, CSS, and JavaScript.

Read. Study. Grow.

BibleVerse Pro is a clean, responsive, installable Progressive Web App (PWA) that helps believers read Scripture, save important verses, take personal notes, listen to audio reading, and grow daily in God's Word.


## ✨ Features

- 📖 Powerful Bible Reader
- 🔍 Instant Scripture Search
- 🌍 Multiple Bible Translations
- 🔊 Audio Bible (Text-to-Speech)
- ⭐ Bookmark Favorite Verses
- 📝 Personal Verse Notes
- 📜 Search History
- 🌙 Dark & Light Theme
- 📅 Daily Verse
- 📱 Fully Responsive Design
- ⚡ Progressive Web App (PWA)
- 💾 Offline-ready Architecture

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/udungeriphymbarr/BibleVerse-Pro.git
```

Open the project

```bash
cd BibleVerse-Pro
```

Launch

Open `index.html` in your browser or use Live Server.
